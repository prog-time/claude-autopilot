# Claude Autopilot

Локальное приложение для macOS: пока разработчик работает, оно в фоне ведёт его open source проекты через Claude Code — берёт GitHub Issues, выполняет их по git-flow (`issues-N` → PR в `develop`), чинит CI, вливает в `develop` и предлагает новые доработки. Человек подтверждает только идеи для задач и PR `develop` → `main`.

Статус: проектирование. Реализация ещё не начата.

## Стек (кратко)

TypeScript, pnpm-монорепозиторий: `packages/shared` (zod-схемы), `packages/server` (Node 22, Fastify, Claude Agent SDK, SQLite + Drizzle), `packages/web` (React 19, Vite, Tailwind 4, TanStack Query). Подробности — ТЗ, раздел 2.

## С чего начать

Этап 1 из ТЗ (раздел 13): каркас монорепозитория, конфиг, БД, шина событий и Fastify. Каждая задача = один issue через `/task_create` со ссылкой на раздел ТЗ.
