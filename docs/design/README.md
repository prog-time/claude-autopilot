# Дизайн панели Claude Autopilot

Живой макет: [Claude Autopilot — дизайн панели](https://claude.ai/artifact/FEV9xvZGTNtJbE1VN7gRfN) (холст claude.ai).
В этой папке — исходники артбордов с холста на 20.11.2026, чтобы макет был под рукой без браузера.

| Файл | Что это |
| --- | --- |
| `Main.dc.html` | Панель — десктоп, 1440 px. Переключатель тёмной темы и цвета акцента — в Tweaks на холсте (`dark`, `accent`) |
| `Mobile.dc.html` | «Ваши решения» на телефоне, 390×844 |
| `canvas.json` | Индекс холста: размеры и порядок артбордов, заметка о стиле |

Файлы `.dc.html` рендерятся только рантаймом холста (`support.js`), открытые локально они не отрисуются. Это справочник по разметке, текстам и токенам. Смотреть дизайн — по ссылке выше.

## Стиль

«Тихий центр управления». Inter — интерфейс, JetBrains Mono — всё техническое (ветки, команды, номера issue, время в ленте). Оранжевый акцент — только то, что ждёт решения человека. Радиусы 8–14 px, сетка отступов 4 px. Тема по умолчанию системная, с переключателем.

## Токены (ТЗ, раздел 9.1)

| Токен | Светлая | Тёмная | Где |
| --- | --- | --- | --- |
| `bg` | #F4F3EF | #0F0F11 | Фон страницы |
| `panel` | #FFFFFF | #18181B | Карточки, шапка |
| `sunk` | #EDECE7 | #232327 | Поля, треки прогресса |
| `line` | #E0DED7 | #2E2E33 | Рамки |
| `text` / `muted` | #18181B / #5F5E58 | #EDEDEF / #A1A1A9 | Текст |
| `accent` | #C2410C | #F97316 | Только ожидание решения человека |
| `run` (фон / текст) | #E2EBFC / #1E40AF | #172554 / #A5C8FF | Выполняется |
| `pr` | #ECE7FD / #5B21B6 | #2B1458 / #C9B8FF | PR → develop |
| `ok` | #DDF3E5 / #166534 | #0B2A17 / #86EFAC | В develop, релиз |
| `err` | #FBE4E2 / #B91C1C | #3A1111 / #FCA5A5 | Ошибки, остановки |

Дополнительно в макете: `wait` (#FDE8D7 / #9A3412, тёмная #3B1A06 / #FDBA74) — бейдж «Ждёт вас»; `queue` = `sunk` / `muted` — «В очереди»; `accentSoft` #FDF0E7 / #2A1608 — фон выбранного варианта ответа; код — #18181B / #F4F4F5 (тёмная #0A0A0C / #E4E4E7).

В реализации токены ложатся в `@theme` Tailwind 4 (`packages/web/src/theme/`), шрифты — через `@fontsource`, без запросов к Google.
