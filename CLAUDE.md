# Claude Autopilot — правила проекта

- Источник требований — `docs/TZ.md`. Перед задачей прочитай раздел ТЗ, на который ссылается issue. Расходишься с ТЗ — скажи об этом, не меняй молча.
- Интерфейс делается по `docs/design/` (токены, тексты, вёрстка) и холсту по ссылке в `docs/design/README.md`. Цвета — только токены из раздела 9.1 ТЗ.
- `prototype/` — справочник по логике конвейера. Не правь его и не импортируй из него код в `packages/`.
- Стек и структура репозитория — ТЗ, разделы 2 и 3. Новые зависимости вне этого списка — только с обоснованием в PR.
- Интерфейс на русском. Код, идентификаторы и коммиты — по правилам `git-commit`.
- Безопасность из раздела 11 ТЗ обязательна: только `127.0.0.1`, внешние команды через `execa` массивом аргументов, никаких токенов в БД, логах и конфиге, приложение никогда не пишет в `main`.
